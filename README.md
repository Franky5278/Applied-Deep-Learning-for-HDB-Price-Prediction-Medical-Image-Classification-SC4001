# Applied Deep Learning for HDB Price Prediction & Medical Image Classification

## Overview

This project explores two applied deep-learning problems:
1. Singapore HDB resale-price prediction using deep neural networks.
2. Binary pneumonia classification from chest X-ray images using convolutional neural networks.

## Part A — HDB Resale Price Prediction

- PyTorch DNN
- Categorical embeddings
- Ray Tune hyperparameter search
- Five-seed ablation studies
- Wide-and-Deep architecture
- RMSE / R² evaluation
- Captum FeatureAblation

## Part B — Chest X-Ray Classification

- AlexNet-like CNN
- VGG-like CNN
- ResNet-like CNN
- Learning-rate and batch-size tuning
- Accuracy / sensitivity / specificity
- Parameter and FLOP analysis
- Grad-CAM explainability

## Dataset

- ~143K Singapore HDB resale transactions
- 5.8K chest X-ray images
